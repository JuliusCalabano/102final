01 / Project Overview

Project Description

Students are required to develop a Menu-Driven Calculator System using C++. The program must allow users to perform basic mathematical operations through a menu-driven interface.

The project assesses your understanding of variables, data types, input/output statements, conditional statements, switch statements, looping structures, and arrays. Your output must be a functional console-based application using concepts discussed during the semester.

Project Objectives

At the end of this project, students should be able to:

  • 1 Apply variables and appropriate data types in a C++ program.
  • 2 Use cin and cout to accept input and display output.
  • 3 Implement if-else and switch statements to control execution.
  • 4 Use loops to perform multiple calculations.
  • 5 Use arrays to store and display calculation history.
  • 6 Integrate the fundamental C++ concepts learned throughout the semester.

02 / System Requirements

Required System Features

Your calculator must implement all the following features. Test each feature before submitting your project.

⌘

1. Menu-Driven Interface

Display a menu with seven options. Use a switch statement to process the selected operation.

[1] Addition
[2] Subtraction
[3] Multiplication
[4] Division
[5] Modulus
[6] View History
[7] Exit
±

2. Arithmetic Operations

Accept the required numbers, perform the selected operation, and display the correct result.

  • • Addition (+)
  • • Subtraction (-)
  • • Multiplication (*)
  • • Division (/)
  • • Modulus (%) — integer remainder
↻

3. Looping Structure

Redisplay the main menu after every calculation until the user chooses Exit. You may use a while loop or do-while loop.

✓

4. Input Validation

Use if-else statements to check special conditions and invalid selections.

  • • Prevent division by zero.
  • • Validate menu choices.
  • • Display appropriate error messages.
▤

5. Calculation History

Store previous calculations in arrays and allow users to view their history. Separate arrays for operands, operators, and results are acceptable.

1. 10 + 5 = 15
2. 20 - 8 = 12
3. 6 * 4 = 24

Use a fixed-size array if desired, and handle maximum capacity.

⏻

6. Program Exit

When the user selects Exit, display a closing message and terminate the program properly.
